# TODO-APP

A To-Do List Application built using the MVC (Model-View-Controller) design pattern with a Login Feature. The app allows users to perform CRUD operations on tasks, filter tasks based on their status (All, Active, Completed), and save tasks in localStorage for persistent storage.

FEATURES : 
✅ User Login: Users can log in using a username and password. Tasks are stored per user.
✅ Add Tasks: Create new tasks with unique IDs.
🖊️ Edit Tasks: Update existing tasks.
🗑️ Delete Tasks: Remove tasks from the list.
✔️ Mark Tasks as Complete: Toggle tasks between completed and active states.
📄 All Tasks: View all tasks in the list.
🔵 Active Tasks: View only active tasks.
🔴 Completed Tasks: View only completed tasks.
💾 Persistent Storage: Tasks are saved in localStorage per user and remain available even after refreshing the page.
